# Superliminal-Glitchless
A set of Glitchless splits for the game Superliminal. Includes both Checkpoints and Levels but not ILs
Make sure to download Livesplit and Superliminal. The Basic Superliminal ASL will be there already. Make sure the Split file you want is downloaded (either Glitchless-Level or Glitchless-Checkpoint)
Right click livesplit and go to open splits from file, click on the split file and it will open the splits for you!
